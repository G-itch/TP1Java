# <span style="color: #4A90E2">Exercícios de Introdução ao Java</span>

Este repositório contém os exercícios práticos de introdução ao Java, incluindo instalação do JDK, configuração da IDE e programas básicos.

## Exercício 1: Instalação do JDK

- Acesse [Oracle JDK Downloads](https://www.oracle.com/java/technologies/downloads/)
- Baixe a versão mais recente do JDK para Windows
- Execute o instalador e siga as instruções
- Verifique a instalação com o comando: `java -version`

## Exercício 2: Instalação da IntelliJ IDEA

- Baixe a IntelliJ IDEA Community Edition em [JetBrains](https://www.jetbrains.com/idea/download/)
- Execute o instalador e siga as instruções
- Configure o JDK na IDE: File > Project Structure > SDKs

## Exercício 3: Criação do Projeto

- Abra a IntelliJ IDEA
- Crie um novo projeto Java
- Nome do projeto: `TP1Java`
- JDK: versão instalada anteriormente

## Exercício 4: Programa Hello World

- Crie a classe `HelloWorld.java`
- Implemente o método main com a mensagem "Hello, World!"

## Exercício 5: Build do Projeto

- Use Build > Build Project (Ctrl+F9)
- Verifique se não há erros de compilação

## Exercício 6: Execução do Programa

- Clique com botão direito em `HelloWorld.java`
- Selecione Run 'HelloWorld.main()'

## Exercício 7: Modificações no Programa

- Modifique a mensagem para incluir seu nome
- Re-execute o programa

## Exercício 8: Variáveis e Tipos de Dados

- Demonstração de diferentes tipos de variáveis
- Uso de System.out.println para exibição

## Exercício 9: Entrada do Usuário

- Implementação com Scanner
- Leitura de nome e idade
- Exibição formatada dos dados

## Exercício 10: Depuração

- Uso de breakpoints
- Step Into e Step Over
- Inspeção de variáveis

## Como Executar

1. Clone este repositório
2. Abra o projeto na IntelliJ IDEA
3. Execute a classe HelloWorld.java

## Estrutura do Projeto

```
src/
  └── main/
      └── java/
          └── HelloWorld.java
```
